# TSG12 – Πλατφόρμα ηλεκτρονικής εγγύησης Thermic

Αυτόνομο WordPress plugin (`thermic-warranty/`) για ενεργοποίηση και διαχείριση εγγυήσεων 12 ετών με σειριακούς αριθμούς:

- **Ενεργοποίηση από τον πελάτη**: σειριακός + email → κωδικός επαλήθευσης → στοιχεία, παραστατικό, όροι & συγκαταθέσεις → μοναδικός κωδικός εγγύησης.
- **Πύλη πελάτη**: σύνδεση με κωδικό μίας χρήσης, λήξη εγγύησης, πρόγραμμα Service, διαχείριση συγκατάθεσης, εξαγωγή/διαγραφή δεδομένων.
- **Ειδοποιήσεις email/SMS**: Service ανά 3 έτη και λήξη, στις −60/−30/0/+30 ημέρες, οριστικό κλείδωμα στις +45 (όλα ρυθμιζόμενα), ημερήσια σύνοψη στην εταιρεία.
- **Διαχειριστικό**: μαζική εισαγωγή σειριακών από Excel/CSV, αναζήτηση προϊόντων/πελατών, καταχώρηση Service, εξαγωγές, αρχείο ειδοποιήσεων.
- **GDPR**: καταγραφή συγκαταθέσεων με έκδοση όρων, IP και χρόνο· ενσωμάτωση στα εργαλεία απορρήτου του WordPress· ανωνυμοποίηση.

Οδηγίες εγκατάστασης και λειτουργίας: [`thermic-warranty/README.txt`](thermic-warranty/README.txt).

Δημιουργία zip για εγκατάσταση:

```bash
zip -r thermic-warranty.zip thermic-warranty
```
